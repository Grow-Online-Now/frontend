Text-First vs Media-First

📝 Text-First (Twitter/LinkedIn)

→ Big textarea as hero
→ Media is optional attachment
→ Character counts prominent
→ Thread support for Twitter
→ Platform selection after writing

📸 Media-First (Instagram/TikTok)

→ Phone preview as hero
→ Caption is secondary
→ Aspect ratio selector prominent
→ Sound, duets, cover frame options
→ Platform selection alongside preview

Why Two Flows?

Different mental models
Twitter users think "what do I want to say?" Instagram users think "what do I want to show?" Forcing one flow on both creates friction.
Media preview is everything
For visual platforms, showing the phone frame preview lets creators see exactly how their content will appear. This builds confidence.
Caption is secondary
The caption input is smaller, on the side. It's important but not the star. Many TikToks have minimal captions anyway.
Platform-specific options surface naturally
Sound selection, duet toggles, cover frame — these matter for TikTok/Reels. They're visible without being overwhelming.
Recent media = speed
Showing recent uploads/camera roll lets creators pick content instantly. No file browser needed for quick posts.
One screen, everything visible
Unlike the text flow's progressive steps, media flow shows everything at once. Creators can preview, caption, and publish without navigating.
