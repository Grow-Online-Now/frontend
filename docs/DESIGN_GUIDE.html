Design System v1.1
Linear meets Notion meets Vercel — dark, typographic, confident, quiet.
Theme Overview

Both themes maintain the same "confident, quiet" personality. Dark uses pure black (#000) as base with white accents. Light uses soft off-white (#fafafa) with subtle shadows for depth instead of borders.

Dark Theme
Ultra-dark backgrounds with subtle elevation through barely-visible borders.
Light Theme
Soft backgrounds with subtle shadows for depth. Clean and minimal.

6. Design Guidelines
✓ Do
  • → Use CSS variables for all colors
  • → Keep semantic colors consistent across themes
  • → Use shadows in light theme for depth
  • → Use borders in dark theme for separation
  • → Test both themes for accessibility
  • → Respect user's system preference
✕ Don't
  • → Hardcode color values
  • → Use pure white (#fff) in light theme backgrounds
  • → Use heavy shadows in dark theme
  • → Let platform colors bleed into UI
  • → Forget to update both theme definitions
  • → Mix themed and non-themed colors
